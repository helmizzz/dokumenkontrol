Aplikasi document control untuk QHSE
Aplikasi document control yang memiliki fitur menyimpan dokumen, untuk keperluan QHSE sebagai administrasi wajib dari tahun ke tahun :
Fitur yang ada :
Dashboard :

1. Menampilkan jumlah dokumen
2. Menampilkan jumlah dokumen publik
3. Menampilkan jumlah dokumen privat
4. Menampilkan jumlah dokumen departemen

Repository dokumen :
Fitur : Dapat menampilkan semua dokumen yang ada di sistem, dapat difilter berdasarkan Tahun, Bulan, departemen, dan sifat dokumen (privat/publik)
Aksi :

- Lihat Dokumen
- Berbagi Dokumen (Privat ke Publik)
- Informasi dokumen
- Edit Dokumen (Apabila dokumen tersebut dilakukan revisi Judul, Tahun, Bulan | apabila dilakukan revisi file maka akan berubah Nomor dokumen, misalkan SOP-HRD-001, jika revisi file maka jadi SOP-HRD-001-1 ada penambahan nomor (-jumlah revisi))

Unggah Dokumen :
Dapat mengupload dokumen dengan melampirkan beberapa file dalam 1 dokumen
Required pengisian : Nomor dokumen, Judul dokumen, Bulan, Tahun, Sifat Dokumen (pilih salah satu)
Dokumen dipilah menjadi 2 kategori : Publik dan Privat
Publik: Dokumen dapat diakses oleh semua user
Privat: Dokumen hanya dapat diakses oleh user yang mengupload dokumen tersebut

Master Data :
Master Departemen : untuk melakukan pendataan Departemen (tambah Departemen)
Master Tahun : untuk melakukan pendataan Tahun (tambah Tahun) sebagai keperluan dokumen

Terdapat 3 Role yaitu Superadmin, Admin, dan User
Manajemen User :
Tambah User : menambah user dengan required : Nama Lengkap, Username, Role Akses, dan Departemen
Edit User : melakukan pengeditan pada user, seperti merubah Role Akses, dan Departemen
Hapus User : merubah status akun

Audit Trail :
Fitur yang ada : Dapat menampilkan semua aktifitas yang dilakukan oleh user, seperti upload dokumen, edit dokumen, hapus dokumen, berbagi dokumen.

Catatan :

- Role Admin dan User tidak dapat menambah atau menghapus Departemen
